# Dashboard Overview

## Header

- **Page title**: Dashboard
- **Greeting**: Good morning, {userName}

## Stats Cards (4 cards)

### Today's Visits
- Count of scheduled visits for today
- Completed / Total (e.g., "8 / 12")
- Link: View schedule

### Pools Serviced This Week
- Count of completed visits this week
- Comparison to last week (+/- %)

### Revenue This Month
- Total from paid invoices this month
- Format as currency ($12,450)
- Comparison to last month

### Past Due Invoices
- Count and total amount
- Warning indicator if > 0
- Link: View invoices

## Quick Actions (3 buttons)

- Start Today's Route
- Add Pool Owner
- Create Invoice

## Today's Schedule

Table/list of today's visits:
- Time
- Pool owner name
- Address
- Service type
- Status (Scheduled, In Progress, Completed)

Show "No visits scheduled" if empty.

## Recent Activity

List of recent events:
- Service completed at {pool}
- Invoice paid by {customer}
- New pool owner added
- Payment received

Show timestamps (e.g., "2 hours ago")

## Sidebar Navigation

- Dashboard (active)
- Schedule
- Pools
- Pool Owners
- Service Logs
- Invoices
- Technicians
- Reports
- Settings
