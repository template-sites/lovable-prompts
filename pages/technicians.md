# Technicians Page

## Header

- **Page title**: Technicians
- **Add button**: Add Technician

## Technician List

Cards showing:
- Photo (or initials avatar)
- Name
- Today's stops: X completed / Y total
- Status: Active / Inactive
- Actions: Edit, View Schedule

## Technician Detail / Edit Modal

### Profile
- Photo upload
- Name
- Email
- Phone
- Color (for calendar)

### Certifications
- CPO Certified (toggle)
- CPO Expiration date

### Status
- Active (toggle)

### Stats (read-only)
- Pools serviced this week
- Average visits per day
- Completion rate

## Technician Performance View

### Header
- Technician name and photo
- Date range selector

### Stats Cards
- Visits completed
- Average per day
- Completion rate (%)
- Average time per visit

### Chart
Visits completed per day (bar chart)

### Recent Activity
List of recent completed visits:
- Date
- Pool
- Duration
- Issues noted

## Add Technician Flow

1. Basic info (name, email, phone)
2. Upload photo (optional)
3. Certifications
4. Assign to routes (optional)

## Empty State

"No technicians added yet."
Button: Add Your First Technician

## Deactivate Confirmation

"Deactivating {name} will unassign them from future visits. Continue?"
- Cancel
- Deactivate
