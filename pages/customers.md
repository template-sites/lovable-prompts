# Pool Owners Page

## Header

- **Page title**: Pool Owners
- **Add button**: Add Pool Owner
- **Search**: Search by name, email, phone
- **Filters**: Status (Active, Inactive, Past Due)

## Pool Owner List

Table columns:
- Name (first + last)
- Pools (count)
- Last Service (date)
- Balance Due ($)
- Status
- Actions

Click row → Pool owner detail page

## Add/Edit Pool Owner Modal

### Contact Info
- First name (required)
- Last name (required)
- Email
- Phone
- Alternate phone

### Preferences
- Preferred contact method: Email, Phone, SMS
- Invoice delivery: Email, Mail

### Notes
- Internal notes (textarea)

## Pool Owner Detail Page

### Header
- Name
- Status badge
- Contact icons (email, phone)
- Edit button

### Contact Info
- Email
- Phone
- Preferred contact method

### Pools Section
List of pools:
- Pool name
- Address
- Last service date
- Link to pool detail

Button: Add Pool

### Balance
- Outstanding balance
- Link to invoices

### Service History
Recent visits across all pools:
- Date
- Pool
- Service type
- Technician

### Invoices
Recent invoices:
- Invoice #
- Date
- Amount
- Status

Button: Create Invoice
