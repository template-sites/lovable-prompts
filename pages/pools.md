# Pools Page

## Header

- **Page title**: Pools
- **Add button**: Add Pool
- **Search**: Search by address or owner name
- **Filters**: Status (Active, Inactive, Seasonal), Service Day

## Pool List

Table columns:
- Address (street, city)
- Pool Owner name
- Type (Inground, Spa, etc.)
- Service Day
- Last Service (date)
- Next Service (date)
- Status
- Actions

Click row → Pool detail page

## Add/Edit Pool Modal

### Pool Owner Section
- Select existing owner or create new
- Owner name, email, phone

### Pool Details
- Pool name (default: "Main Pool")
- Type: Inground, Above Ground, Spa, Infinity
- Surface: Plaster, Pebble, Vinyl, Fiberglass, Tile
- Volume (gallons)
- Saltwater? (toggle)
- Has heater? (toggle)

### Equipment
- Pump model
- Filter type and size
- Heater model
- Salt cell model
- Auto cleaner model

### Address
- Street
- City
- State
- Zip

### Access
- Gate code
- Access notes (textarea)

### Service Schedule
- Service day (Mon-Fri)
- Frequency: Weekly, Bi-weekly, Monthly
- Base price per visit

## Pool Detail Page

### Header
- Pool name and address
- Owner name (link to owner)
- Status badge
- Edit button, Archive button

### Quick Info
- Pool type, surface, volume
- Equipment list
- Gate code
- Access notes

### Service Schedule
- Day and frequency
- Price per visit
- Next scheduled visit

### Chemical History
Chart showing readings over time:
- pH
- Chlorine
- Alkalinity

### Service History
List of recent visits:
- Date
- Technician
- Status
- Notes preview
- Link to service log

### Photos
Gallery of service photos
