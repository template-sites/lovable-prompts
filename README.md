# MusicLessonPro Marketing Website

Build a complete marketing website for MusicLessonPro, a music studio management software.

## Tech Stack
- Vite + React + TypeScript
- shadcn/ui components
- Tailwind CSS
- React Router

## Pages to Build
Read each file in the `pages/` folder and build that page.

## Design Guidelines
- Modern, clean aesthetic
- Music-themed but professional
- Target audience: Music teachers and studio owners
- Mobile responsive

## Navigation
- Logo: "MusicLessonPro"
- Nav: Features, Pricing, About, Contact, Login (button), Start Free Trial (primary button)
- Footer: Links to all pages, social icons, copyright
