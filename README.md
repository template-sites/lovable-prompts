# MusicLessonPro Template Sites

Build 3 example music studio tenant websites. Each site has a different personality and target audience.

## Tech Stack
- Vite + React + TypeScript
- shadcn/ui components
- Tailwind CSS
- React Router

## Sites to Build

### 1. Harmony Digital Music Academy (/sites/harmony)
Modern, tech-forward music school. Online lessons focus. Young adult target.

### 2. Riverdale Music Studio (/sites/riverdale)
Family-friendly, local community music studio. Kids and families target.

### 3. Metropolitan Conservatory (/sites/metropolitan)
Professional, classical music focus. Serious students and adults target.

## Each Site Needs
- Home page (hero, services, testimonials, CTA)
- About page (story, instructors)
- Services page (lessons offered, pricing)
- Contact page (form, location, hours)

## Design
Each site should have a distinct visual identity appropriate to its personality.
