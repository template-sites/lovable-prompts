# PoolPro Tenant Site Templates

Build 3 complete pool service company websites. These are customer-facing websites for pool service businesses using PoolPro.

## Sites to Build

### 1. Crystal Clear Pool Service
Modern, tech-forward design. Premium service positioning.
See `sites/crystalclear/` for content.

### 2. Blue Wave Pool Care
Family-friendly, approachable. Community-focused.
See `sites/bluewave/` for content.

### 3. AquaPro Pool Services
Professional, minimal. Commercial focus.
See `sites/aquapro/` for content.

## Shared Structure

Each site should have:
- Home page with hero, services, testimonials, CTA
- Services page with detailed offerings
- About page with company story
- Contact page with form
- Booking integration (button that says "Book Service")

## Requirements

- Build all 3 sites as separate route groups
- Each site has distinct personality
- All content provided in site folders
- Include realistic photos placeholder areas
- Mobile responsive
