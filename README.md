# MusicLessonPro - Teacher Website Examples

Build 3 complete, professional teacher websites to showcase how MusicLessonPro helps teachers create their online presence.

**IMPORTANT:** These are NOT demo pages - they are fully functional, professional websites that a real music teacher would use. Every button and link must work.

## Tech Stack
- Vite + React + TypeScript
- shadcn/ui components
- Tailwind CSS
- React Router

## CRITICAL REQUIREMENTS

### All Buttons and Links Must Work
- Every "Learn More" button must navigate to the relevant page
- Every "Book Now" / "Get Started" button must go to the Contact page
- Navigation must work on all pages
- Footer links must all be functional

### Dark Mode / Light Mode
- Each site should have a theme toggle
- All content must be readable in both modes
- Use appropriate color schemes for each site's personality

### Required Pages for EACH Site
1. **Home** - Hero, features, testimonials, CTA
2. **About** - Story, team/instructors, philosophy
3. **Programs** (or Services/Lessons) - All lesson types with pricing
4. **Contact** - Form, location/hours, FAQ
5. **Privacy Policy** - Standard privacy policy page
6. **Terms of Service** - Standard terms page

### Footer on Every Page
Each site must have a consistent footer with:
- Logo and tagline
- Quick links (Home, About, Programs, Contact)
- Legal links (Privacy Policy, Terms of Service)
- Contact info (email, phone)
- Social media icons
- Copyright notice

## Sites to Build

### 1. Harmony Digital Music Academy (`/harmony/*`)
- **Personality:** Modern, tech-forward, innovative
- **Color scheme:** Dark slate, neon accents (purple, cyan)
- **Target:** Young adults, teens, remote learners
- **Unique angle:** 100% online lessons, technology-focused

### 2. Riverdale Music Studio (`/riverdale/*`)
- **Personality:** Warm, family-friendly, community
- **Color scheme:** Warm yellows, friendly greens, cream
- **Target:** Kids, families, beginners
- **Unique angle:** In-person lessons, family discounts, recitals

### 3. Metropolitan Conservatory (`/metropolitan/*`)
- **Personality:** Professional, classical, prestigious
- **Color scheme:** Navy, gold, burgundy
- **Target:** Serious students, adults, audition prep
- **Unique angle:** Conservatory-level training, professional faculty

## Navigation Structure

Each site should have this navigation:
```
[Logo] Home | About | Programs | Contact           [Theme Toggle]
```

## Content Files
Read each site's `site.md` file for complete content including:
- Page copy and headlines
- Testimonials
- Pricing tables
- Teacher bios
- FAQ content

## Design Quality
- Professional, polished appearance
- Smooth animations and transitions
- Mobile-responsive (hamburger menu on mobile)
- Fast loading, optimized images
- Accessible (proper contrast, alt text, ARIA labels)
